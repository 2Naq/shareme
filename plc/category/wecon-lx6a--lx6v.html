Wecon (LX6A / LX6V)

Tài liệu kỹ thuật và sổ tay hướng dẫn lập trình PLC Wecon dòng LX6V / LX6A500 trên phần mềm PLC Editor 2 chuẩn PLCopen.

📄️00. Tổng quan tài liệu Wecon

Sổ tay hướng dẫn kỹ thuật toàn diện cho dòng PLC Wecon LX6V / LX6A500 lập trình trên phần mềm PLC Editor 2 chuẩn quốc tế IEC 61131-3.

📄️01 Execution of the Program

Nguyên lý chu kỳ quét (Scan Cycle), thời gian xử lý vòng lặp và thứ tự thực thi chương trình trong PLC Wecon LX6V.

📄️02 Devices

Bản đồ và phân loại vùng nhớ thiết bị trên PLC Wecon: X, Y, M, S, SM, T, C, D, R, SD.

📄️03 Sequence Control

Kỹ thuật lập trình điều khiển quá trình tuần tự SFC / STL trên PLC Wecon.

📄️04 Program Flow

Các lệnh rẽ nhánh có điều kiện, gọi chương trình con và vòng lặp trong PLC Editor 2.

📄️05 Timer and Counter

Hướng dẫn sử dụng Timer và Counter độ chính xác cao trên PLC Wecon.

📄️06 Basic instructions

Tập hợp các lệnh tiếp điểm logic, cuộn dây ngõ ra và lệnh sườn xung cơ bản.

📄️07 EtherCAT

Hướng dẫn thiết lập và cấu hình mạng truyền thông Bus EtherCAT cho Servo Drive trên Wecon LX6V.

🗃08 Motion Control

13 items

📄️09 High Speed Counter

Cấu hình bộ đếm tốc độ cao HSC đọc Encoder 1 pha, 2 pha AB trên PLC Wecon.

📄️10 Communication Instruction

Tập lệnh truyền thông nối tiếp RS-485 / RS-422 qua Modbus RTU / ASCII.

📄️11 PID Control Instruction

Lập trình điều khiển vòng kín nhiệt độ, áp suất PID với tính năng Auto-tuning.

📄️12 Character String Instruction

Tập lệnh thao tác chuỗi ký tự, ghép chuỗi, tách chuỗi và chuyển đổi kiểu dữ liệu.

📄️13 Ethernet Communication

Cấu hình cổng mạng Ethernet tích hợp trên PLC Wecon LX6V: Modbus TCP, Socket TCP/UDP.

📄️14 Built-in FC/FB

Danh mục các hàm (FC) và khối hàm (FB) định nghĩa sẵn trong PLC Editor 2.

📄️15 ST Help Manual

Cẩm nang cú pháp, toán tử và cấu trúc lập trình ngôn ngữ Structured Text IEC 61131-3.

📄️Appendixes

Bảng tra cứu thông số kỹ thuật phần cứng, kích thước đấu dây và so sánh LX6V / LX6S / A500.

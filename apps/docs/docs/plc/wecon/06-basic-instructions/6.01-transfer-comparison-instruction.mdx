## MOV/Truyền dữ liệu 16-bit

MOV(P)

Truyền dữ liệu nhị phân (BIN) 16-bit từ vùng nhớ thiết bị chỉ định tại (s) sang vùng nhớ thiết bị chỉ định tại (d).

-[MOV (s) (d)]

#### Nội dung, phạm vi và kiểu dữ liệu

| Tham số | Nội dung mô tả                                       | Phạm vi giá trị | Kiểu dữ liệu | Kiểu dữ liệu (Nhãn biến) |
| :------ | :--------------------------------------------------- | :-------------- | :----------- | :----------------------- |
| (s)     | Transmit source data or địa chỉ thiết bị stored data | -32768 to 32767 | Signed BIN16 | ANY16_S                  |
| (d)     | Số hiệu thiết bị đích truyền                         | -               | Signed BIN16 | ANY16_S                  |

#### Đặc tính kỹ thuật

• Truyền dữ liệu nhị phân (BIN) 16-bit được chỉ định tại (s) sang vùng nhớ thiết bị chỉ định tại (d).

Khi M0 được SET (ON), giá trị của D0 được truyền sang giá trị của D2: (D0)→(D2).

### BMOV/Truyền dữ liệu hàng loạt (khối)

BMOV(P)

Dữ liệu nhị phân (BIN) 16-bit gồm (n) điểm bắt đầu từ vùng nhớ thiết bị chỉ định tại (s) được truyền tuần tự sang vùng nhớ thiết bị chỉ định tại (d).

-[BMOV (s) (d) (n)]

#### Nội dung, phạm vi và kiểu dữ liệu

| Tham số | Nội dung mô tả                          | Phạm vi giá trị | Kiểu dữ liệu | Kiểu dữ liệu (Nhãn biến) |
| :------ | :-------------------------------------- | :-------------- | :----------- | :----------------------- |
| (s)     | Thiết bị bắt đầu lưu trữ dữ liệu truyền | -               | Signed BIN16 | ANY16_S                  |
| (d)     | Thiết bị bắt đầu của đích truyền        | -               | Signed BIN16 | ANY16_S                  |
| (n)     | Number of transmission                  | 1 ≤ n ≤ 512     | Signed BIN16 | ANY16_S                  |

#### Đặc tính kỹ thuật

Truyền hàng loạt (khối) dữ liệu nhị phân (BIN) 16-bit gồm (n) điểm bắt đầu từ vùng nhớ thiết bị chỉ định tại (s) sang vùng nhớ thiết bị chỉ định tại (d).

![Sơ đồ kỹ thuật](https://docs.we-con.com.cn/bin/download/PLC%20Editor2%20%28LX6A500%29/07%20Basic%20instructions/Cycle%20Shift%20instruction/WebHome/1760061766238-444.png?rev=1.1)

Khi số hiệu thiết bị vượt quá phạm vi, việc truyền dữ liệu sẽ chỉ được thực hiện trong phạm vi cho phép.

Bằng cách điều khiển cờ đảo chiều (SM224) của lệnh BMOV, dữ liệu nhị phân (BIN) 16-bit gồm (n) điểm bắt đầu từ thiết bị chỉ định tại (d) có thể được truyền hàng loạt sang thiết bị chỉ định tại (s).

#### Mã lỗi (Error Code)

| Mã lỗi (Error Code) | Nội dung mô tả                                                                             |
| :------------------ | :----------------------------------------------------------------------------------------- |
| 4084H               | In lệnh ứng dụng (n) input the data exceeds the specified range                            |
| 4085H               | The output results of (s) and (n) in read lệnh ứng dụng vượt quá phạm vi vùng nhớ thiết bị |
| 4086H               | Kết quả xuất ra tại (d) trong lệnh ghi vượt quá phạm vi vùng nhớ thiết bị cho phép         |

#### Ví dụ minh họa

![Sơ đồ kỹ thuật](https://docs.we-con.com.cn/bin/download/PLC%20Editor2%20%28LX6A500%29/07%20Basic%20instructions/Cycle%20Shift%20instruction/WebHome/1760061792170-804.png?rev=1.1)

Khi M0 được SET (ON), SET M1, khi đó (D5)→(D10); (D6)→(D11); (D7)→(D12);

Khi M0 được RESET (OFF), SET M1, khi đó (D10)→(D5); (D11)→(D6); (D12)→(D7).

### SMOV/Dịch chuyển dữ liệu theo chữ số (4-bit)

SMOV(P)

Lệnh dùng để phân tách và tổng hợp dữ liệu theo đơn vị chữ số (digit, 4 bit).

-[SMOV (s) (n1) (n2) (d) (n3)]

| Tham số | Nội dung mô tả                                               | Phạm vi giá trị | Kiểu dữ liệu | Kiểu dữ liệu (Nhãn biến) |
| :------ | :----------------------------------------------------------- | :-------------- | :----------- | :----------------------- |
| (s)     | Số hiệu thiết bị word lưu trữ dữ liệu có bit cần dịch chuyển |                 | Signed BIN16 | ANY16_S                  |

Nếu (D0) &gt; (100000) thì Y0 ON.

Nếu (0) ≤ (D0) ≤ (100000) thì Y1 ON.

Nếu (D0) &lt; (0) thì Y2 ON.

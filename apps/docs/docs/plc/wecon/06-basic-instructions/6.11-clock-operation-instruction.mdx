### TADD / Phép cộng dữ liệu đồng hồ thời gian thực (RTC)

TADD(P)

Cộng dữ liệu thời gian lưu từ số hiệu thiết bị được chỉ định tại (s1) trở đi với dữ liệu thời gian lưu từ số hiệu thiết bị được chỉ định tại (s2) trở đi, rồi lưu kết quả phép cộng từ số hiệu thiết bị được chỉ định tại (d) trở đi.

-[TADD (s1) (s2) (d)]

#### Nội dung, phạm vi và kiểu dữ liệu

| Tham số | Nội dung mô tả                                                                             | Phạm vi giá trị | Kiểu dữ liệu      | Kiểu dữ liệu (Nhãn biến)            |
| :------ | :----------------------------------------------------------------------------------------- | :-------------- | :---------------- | :---------------------------------- |
| (s1)    | Số hiệu thiết bị bắt đầu lưu trữ dữ liệu thời gian bị cộng                                 | -               | Signed BIN 16 bit | ANY16_ARRAY (number of elements: 3) |
| (s2)    | Số hiệu thiết bị bắt đầu lưu trữ dữ liệu thời gian dùng cho phép cộng                      | -               | Signed BIN 16 bit | ANY16_ARRAY(number of elements: 3)  |
| (d)     | The device start number that stores the time (time) data of the addition kết quả phép toán | -               | Signed BIN 16 bit | ANY16_ARRAY(number of elements: 3)  |

#### Vùng nhớ thiết bị hỗ trợ (Device Used)

| TADD             | Parameter 2 |     |     |     |     |     |        |        |         |          |     |     |     |     |     |  ●  |  ●  |  ●  |  ●  |  ●  |     |     |     |     |     |           ●           |         ●          |
| TADD             | Parameter 3 |     |     |     |     |     |        |        |         |          |     |     |     |     |     |  ●  |  ●  |  ●  |  ●  |  ●  |     |     |     |     |     |           ●           |         ●          |

#### Đặc tính kỹ thuật

Cộng dữ liệu thời gian được chỉ định tại (s1) với dữ liệu thời gian được chỉ định tại (s2), rồi lưu kết quả phép cộng từ số hiệu thiết bị được chỉ định tại (d) trở đi.

![Sơ đồ kỹ thuật](https://docs.we-con.com.cn/bin/download/PLC%20Editor2%20%28LX6A500%29/07%20Basic%20instructions/6.11%20Clock%20Operation%20instruction/WebHome/1760927361239-421.png?rev=1.1)

#### Ví dụ minh họa

Khi cộng 6:32:40 và 7:48:10 lại với nhau

![Sơ đồ kỹ thuật](https://docs.we-con.com.cn/bin/download/PLC%20Editor2%20%28LX6A500%29/07%20Basic%20instructions/6.11%20Clock%20Operation%20instruction/WebHome/1760927400122-294.png?rev=1.1)

Khi thời gian kết quả tính toán vượt quá 24 giờ, cờ nhớ (Carry) sẽ bật ON và giá trị sau khi trừ đi 24 giờ trở thành kết quả tính toán. Ví dụ, khi cộng 14:20:30 và 20:20:20, kết quả không phải là 34:40:50 mà là 10:40:50.

![Sơ đồ kỹ thuật](https://docs.we-con.com.cn/bin/download/PLC%20Editor2%20%28LX6A500%29/07%20Basic%20instructions/6.11%20Clock%20Operation%20instruction/WebHome/1760927425472-874.png?rev=1.1)

Khi kết quả tính toán bằng 0 (0 giờ, 0 phút, 0 giây), cờ không (Zero) sẽ bật ON.

Khi cộng 23:59:59 và 1 giây, kết quả tính toán là 0:00:00, đồng thời cờ nhớ (Carry) và cờ không (Zero) đều bật ON.

Các thiết bị liên quan như sau:

| Vùng nhớ thiết bị (Devices) | Tên                 | Nội dung mô tả                                                                          |
| :-------------------------- | :------------------ | :-------------------------------------------------------------------------------------- |
| SM151                       | Cờ nhớ (Carry)      | Bật ON khi kết quả của lệnh TADD(P) vượt quá giá trị dữ liệu đồng hồ tối đa là 23:59:59 |
| SM153                       | Cờ giá trị 0 (Zero) | Bật ON khi kết quả của lệnh TADD(P) là 0:00:00                                          |

:::tip
✎Lưu ý

Các thiết bị được chỉ định tại (s1), (s2), (d) mỗi thiết bị chiếm 3 điểm tương ứng. Lưu ý không để trùng lặp với các thiết bị dùng để điều khiển máy.

Khi sử dụng dữ liệu thời gian (giờ, phút, giây) của đồng hồ thời gian thực (RTC) tích hợp trong mô-đun CPU, hãy sử dụng lệnh TRD(P) để đọc giá trị của thanh ghi đặc biệt và gán thiết bị từ cho từng toán hạng.
:::

#### Mã lỗi (Error Code)

| Mã lỗi (Error Code) | Nội dung mô tả                                                                                                                                         |
| :------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 4085H               | Khi vùng nhớ thiết bị chỉ định để đọc vượt quá giới hạn của thiết bị tương ứng                                                                         |
| 4086H               | Khi vùng nhớ thiết bị chỉ định để ghi vượt quá giới hạn của thiết bị tương ứng                                                                         |
| 4084H               | Khi giá trị chỉ định tại (s1) và (s2) nằm ngoài phạm vi 0 đến 23; Khi giá trị chỉ định tại (s1)+1, (s2)+1, (s1)+2 và (s2)+2 nằm ngoài phạm vi 0 đến 59 |

### TSUB / Phép trừ dữ liệu đồng hồ thời gian thực (RTC)

TSUB(P)

Trừ dữ liệu thời gian lưu từ số hiệu thiết bị được chỉ định tại (s1) trở đi cho dữ liệu thời gian lưu từ số hiệu thiết bị được chỉ định tại (s2) trở đi, rồi lưu kết quả phép trừ từ số hiệu thiết bị được chỉ định tại (d) trở đi.

-[TSUB (s1) (s2) (d)]

### TRD / Đọc dữ liệu đồng hồ thời gian thực (RTC)

TRD(P)

Đọc dữ liệu đồng hồ của đồng hồ thời gian thực (RTC) tích hợp trong mô-đun CPU.

-[TRD (d)]

| Tham số | Nội dung mô tả                                       | Phạm vi giá trị | Kiểu dữ liệu      | Kiểu dữ liệu (Nhãn biến)            |
| :------ | :--------------------------------------------------- | :-------------- | :---------------- | :---------------------------------- |
| (d)     | Số hiệu thiết bị bắt đầu và đích đọc dữ liệu đồng hồ | -               | Signed BIN 16 bit | ANY16_ARRAY (number of elements: 7) |

| Khối lệnh / Lệnh | Tham số     |  X  |  Y  |  M  |  S  | SM  | T(bit) | C(bit) | LC(bit) | HSC(bit) | D.b | KnX | KnY | KnM | KnS |  T  |  C  |  D  |  R  | SD  | LC  | HSC |  K  |  H  |  E  | Sửa đổi chỉ mục ([D]) | Mở rộng xung (XXP) |
| :--------------- | :---------- | :-: | :-: | :-: | :-: | :-: | :----: | :----: | :-----: | :------: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-------------------: | :----------------: |

| Special register | SD102   | Hour             | 0 to 23            | →   | (d)+3   | Hour             |
| Special register | SD101   | Minute           | 0 to 59            | →   | (d)+4   | Minute           |

| SD104                       | Dữ liệu tháng của dữ liệu đồng hồ được lưu ở mã BIN.                                                     |
| SD105                       | Dữ liệu năm của dữ liệu đồng hồ được lưu ở mã BIN 4 chữ số theo dương lịch.                              |
| SD106                       | Dữ liệu thứ trong tuần của dữ liệu đồng hồ được lưu ở mã BIN (0: Chủ Nhật, 1: Thứ Hai, ..., 6: Thứ Bảy). |

### HOUR / Đo thời gian theo giờ 16-bit

HOUR(P)

#### Đặc tính kỹ thuật

Thời gian ON của tiếp điểm ngõ vào được đo theo đơn vị 1 giờ. Khi thời gian ON tích lũy vượt quá thời gian (dữ liệu BIN 16-bit) được chỉ định tại (s), thiết bị được chỉ định tại (d2) sẽ bật ON.

• Tại (s), cài đặt thời gian cho đến khi cảnh báo (d2) bật ON theo đơn vị 1 giờ.

• (d1) lưu giá trị đo hiện tại theo đơn vị 1 giờ.

• Nếu giá trị hiện tại của (d1) vượt quá 32767, nó sẽ được giữ ở mức 32767.

• (d1)+1 lưu giá trị đo hiện tại (theo đơn vị 1 giây) nhỏ hơn 1 giờ.

• (d2) bật ON khi giá trị hiện tại (d1) vượt quá thời gian được chỉ định tại (s).

• Để tiếp tục sử dụng dữ liệu giá trị hiện tại ngay cả sau khi ngắt nguồn mô-đun CPU, hãy chỉ định thanh ghi dữ liệu có chức năng lưu giữ khi mất điện cho (d1). Nếu sử dụng thanh ghi dữ liệu thông thường, dữ liệu giá trị hiện tại sẽ bị xóa khi tắt nguồn mô-đun CPU và khi chuyển thao tác STOP → RUN.

• Sau khi ngõ ra cảnh báo được chỉ định tại (d2) bật ON, quá trình đo vẫn tiếp tục.

• Quá trình đo dừng lại khi giá trị hiện tại đạt giá trị tối đa 16-bit. Để tiếp tục đo, hãy xóa giá trị hiện tại từ (d1) đến (d1)+1.

• Sau khi lệnh ngừng chạy, quá trình đo dừng lại và ngõ ra tiếp tục được duy trì.

### TZCP / So sánh vùng dữ liệu đồng hồ thời gian thực (RTC)

TZCP(P)

### DACOS / Phép toán COS-1 số thực độ chính xác đơn

DACOS(P)

After calculating the COS -1 (arc cosine) value of the angle specified in (s), the kết quả tính toán is stored in địa chỉ thiết bị specified in (d).

#### Đặc tính kỹ thuật

After calculating the COS -1 (arc cosine) value of the angle specified in (s), the kết quả tính toán is stored in địa chỉ thiết bị specified in (d).

![Sơ đồ kỹ thuật](https://docs.we-con.com.cn/bin/download/PLC%20Editor2%20%28LX6A500%29/07%20Basic%20instructions/6.9%20Floating%20Point%20instructions/WebHome/1760606570282-544.png?rev=1.1)

Giá trị COS được chỉ định tại (s) có thể cài đặt trong phạm vi từ -1.0 đến 1.0.

Góc (kết quả tính toán) lưu tại (d) được lưu với giá trị từ 0 đến π theo đơn vị radian.

Các thiết bị liên quan như sau:

| Vùng nhớ thiết bị (Devices) | Tên | Nội dung (Điều kiện) | Nội dung (Thao tác xử lý) |
| :--- | :--- | :--- | :--- |
| SM153 | Cờ giá trị 0 (Zero) | Kết quả phép toán bằng 0 | Cờ báo giá trị 0 (SM153) bật lên ON. |
| SM152 | Cờ mượn (Borrow) | The absolute value of kết quả phép toán&lt;2 -126 | Giá trị của (d) trở thành giá trị nhỏ nhất của số thực 32-bit (2^-126) và cờ mượn (SM152) bật ON. |

#### Mã lỗi (Error Code)

| Mã lỗi (Error Code) | Nội dung mô tả |
| :--- | :--- |
| 4085H | Địa chỉ tại (s) vượt quá giới hạn vùng nhớ thiết bị cho phép |
| 4086H | Địa chỉ ghi tại (d) vượt quá giới hạn vùng nhớ thiết bị cho phép |
| 4084H | When the content of thiết bị được chỉ định bởi (s) is an irregular number, a non-number, ±∞ and exceeds -1.0 to 1.0 |

Dù chuỗi ký tự chỉ định ở dạng thập phân hay dạng số mũ thì đều có thể chuyển đổi thành dữ liệu số thực dấu phẩy động nhị phân.

Có thể cài đặt tối đa 24 ký tự cho chuỗi ký tự. Các mã 20H (khoảng trắng) và 30H (0) trong chuỗi ký tự cũng được tính là 1 ký tự.

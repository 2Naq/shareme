### ADD/Phép toán cộng 16-bit

ADD(P)

Cộng dữ liệu BIN 16-bit chỉ định tại (s1) và dữ liệu BIN 16-bit chỉ định tại (s2), sau đó lưu kết quả vào thiết bị chỉ định tại (d).

-[ADD (s1) (s2) (d)]

#### Nội dung, phạm vi và kiểu dữ liệu

| Tham số | Nội dung mô tả | Phạm vi giá trị | Kiểu dữ liệu | Kiểu dữ liệu (Nhãn biến) |
| :--- | :--- | :--- | :--- | :--- |
| (s1) | Dữ liệu phép cộng hoặc thiết bị lưu trữ dữ liệu cộng | -32768 to 32767 | Signed BIN16 | ANY16_S |
| (s2) | Dữ liệu phép cộng hoặc thiết bị lưu trữ dữ liệu cộng | -32768 to 32767 | Signed BIN16 | ANY16_S |
| (d) | Thiết bị lưu trữ kết quả phép toán |  | Signed BIN16 | ANY16_S |

Cộng dữ liệu BIN 16-bit chỉ định tại (s1) và dữ liệu BIN 16-bit chỉ định tại (s2), sau đó lưu kết quả phép cộng vào thiết bị chỉ định tại (d).

| SM152 | Cờ mượn (Borrow) | When the kết quả phép toán is less than -32,768, the borrow flag will be (ON). |
| SM153 | Điểm không (Zero) | When the kết quả phép toán is 0, the zero flag will be (ON). |

![Sơ đồ kỹ thuật](https://docs.we-con.com.cn/bin/download/PLC%20Editor2%20%28LX6A500%29/07%20Basic%20instructions/Arithmetic%20Operation%20instructions/WebHome/1760427227810-245.png?rev=1.1)

:::tip
✎Lưu ý:

- Khi toán hạng nguồn và toán hạng đích được chỉ định là cùng một thiết bị:

Toán hạng nguồn và toán hạng đích cũng có thể được chỉ định cùng một số hiệu thiết bị.

Trong trường hợp này, nếu sử dụng lệnh thực thi liên tục (ADD, DADD), kết quả của phép toán cộng sẽ thay đổi sau mỗi chu kỳ quét.

- Sự khác biệt giữa lệnh ADD và lệnh INC khi sử dụng chương trình thực hiện phép cộng +1:

ADD[P] có nghĩa là mỗi khi X001 chuyển từ OFF sang ON, nội dung của D0 được cộng thêm 1.

Mặc dù lệnh này rất giống với lệnh INCP được mô tả ở phần sau, nhưng có một số điểm khác biệt như sau.

|  |  |  | Các lệnh ADD/ADDP/DADD/DADDP | Các lệnh INC/INCP/DINC/DINCP |
| :--- | :--- | :--- | :--- | :--- |
| bit cờ (bằng 0, mượn, nhớ) |  |  | Hành động thực thi | No action |
| Kết quả tính toán | Kết quả phép toán 16-bit | (S) + (+1) = (d) | 32767 → 0 → +1 → +2 → | 32767→-32768→-32767 |
| Kết quả tính toán | Kết quả phép toán 16-bit | (S) + (-1) = (d) | ← -2 ← -1 ← 0 ← -32768 | —— |
| Kết quả tính toán | • Kết quả phép toán bit | (S) + (+1) = (d) | 2147483647 → 0 → +1 → +2 → | 2147483647 → -2147483648→ -2147483647 |
| Kết quả tính toán | • Kết quả phép toán bit | (S) + (-1) = (d) | ← -2 ← -1 ← 0 ← -2147483648 | —— |
:::

#### Mã lỗi (Error Code)

| Mã lỗi (Error Code) | Nội dung mô tả |

| 4086H | Kết quả xuất ra tại (d) trong lệnh ghi vượt quá phạm vi vùng nhớ thiết bị cho phép |

![Sơ đồ kỹ thuật](https://docs.we-con.com.cn/bin/download/PLC%20Editor2%20%28LX6A500%29/07%20Basic%20instructions/Arithmetic%20Operation%20instructions/WebHome/1760427855492-362.png?rev=1.1)

Trong trường hợp thiết bị word, kết quả phép chia sử dụng BIN 64-bit để lưu thương số và số dư. Trong trường hợp thiết bị bit, chỉ sử dụng BIN 32-bit để lưu thương số.

:::tip
✎Lưu ý:

- Về kết quả phép toán

• Bit cao nhất của thương số và số dư biểu thị dấu dương (0) và âm (1).

• Khi một trong hai giá trị (s1) hoặc (s2) âm, thương số sẽ mang dấu âm. Khi (s1) âm, số dư sẽ mang dấu âm.

- Thiết bị được chỉ định của (d)

• Với chức năng chỉ định chữ số, khi chỉ định thiết bị bit thì không thể lấy được số dư.
:::

#### Mã lỗi (Error Code)

| Mã lỗi (Error Code) | Nội dung mô tả |
| :--- | :--- |
| 4080H | The input of divisor (s2) is 0 |
| 4085H | Phạm vi đọc tại (s1) và (s2) trong lệnh ứng dụng vượt quá giới hạn vùng nhớ thiết bị |
| 4086H | Kết quả xuất ra tại (d) trong lệnh ghi vượt quá phạm vi vùng nhớ thiết bị cho phép |

#### Ví dụ minh họa

![Sơ đồ kỹ thuật](https://docs.we-con.com.cn/bin/download/PLC%20Editor2%20%28LX6A500%29/07%20Basic%20instructions/Arithmetic%20Operation%20instructions/WebHome/1760427878768-598.png?rev=1.1)

Chia dữ liệu trong (D1, D0) cho (D3, D2) và lưu kết quả tính toán: thương số lưu vào (D5, D4) và số dư lưu vào (D7, D6), tức là (D1, D0)/(D3, D2) → (D5, D4) (thương số) (D7, D6) (số dư).

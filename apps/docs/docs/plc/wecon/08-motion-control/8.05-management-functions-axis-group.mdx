## Các chức năng quản lý điều khiển chuyển động nhóm trục

![Sơ đồ kỹ thuật](https://docs.we-con.com.cn/bin/download/PLC%20Editor2%20%28LX6A500%29/08%20Motion%20Control/8.05%20Management%20functions%20of%20axis%20group%20motion%20control/WebHome/1708999788060-281.png?rev=1.1)

Khối hàm này dùng để thêm trục vào nhóm trục.

#### Vùng nhớ thiết bị hỗ trợ (Chỉ sử dụng một biến thiết bị đơn lẻ, không hỗ trợ ghép chuỗi hoặc chỉ mục)

| :---------------- | :----------- | :-: | :-: | :-: | :-: | :-: | :----: | :----: | :-----: | :------: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-------------------: | :----------------: |
| MC_ADDAXISTOGROUP | Execute      |  ●  |  ●  |  ●  |  ●  |  ●  |        |        |         |          |     |     |     |     |     |     |     |     |     |     |     |     |     |     |     |                       |                    |
| MC_ADDAXISTOGROUP | IdentInGroup |     |     |     |     |     |        |        |         |          |     |     |     |     |     |     |     |     |     |     |     |     |     |     |     |                       |                    |
| MC_ADDAXISTOGROUP | AxesGroup    |     |     |     |     |     |        |        |         |          |     |     |     |     |     |     |     |     |     |     |     |     |     |     |     |                       |                    |
| MC_ADDAXISTOGROUP | Axis         |     |     |     |     |     |        |        |         |          |     |     |     |     |     |     |     |     |     |     |     |     |     |     |     |                       |                    |
| MC_ADDAXISTOGROUP | Done         |     |  ●  |  ●  |  ●  |  ●  |        |        |         |          |     |     |     |     |     |     |     |     |     |     |     |     |     |     |     |                       |                    |
| MC_ADDAXISTOGROUP | Busy         |     |  ●  |  ●  |  ●  |  ●  |        |        |         |          |     |     |     |     |     |     |     |     |     |     |     |     |     |     |     |                       |                    |
| MC_ADDAXISTOGROUP | Error        |     |  ●  |  ●  |  ●  |  ●  |        |        |         |          |     |     |     |     |     |     |     |     |     |     |     |     |     |     |     |                       |                    |

#### Lưu ý khi sử dụng vùng nhớ thiết bị

▪LC và HSC là các kiểu dữ liệu 32-bit có dấu;

▪T, C, D, R và SD là các kiểu dữ liệu 16-bit có dấu;

#### Bảng thông số chân và kiểu biến (Variable Type Used)

| Khối lệnh / Lệnh  | Kiểu chân       | Tham số      | Kiểu dữ liệu | Cho phép để trống | Phạm vi giá trị | Mô tả kỹ thuật                             |
| :---------------- | :-------------- | :----------- | :----------- | :---------------- | :-------------- | :----------------------------------------- |
| MC_ADDAXISTOGROUP | Ngõ vào (Input) | Execute      | BOOL         | Không             | TRUE/FALSE      | Kích hoạt khối hàm (Enable)                |
| MC_ADDAXISTOGROUP | Ngõ vào (Input) | IdentInGroup | WORD         | Không             | [0 to 2]        | Cờ thứ tự trục                             |
| MC_ADDAXISTOGROUP | Ngõ vào (Input) | AxesGroup    | WORD         | Không             | [0 to 65535]    | Số hiệu định danh nhóm trục (AxesGroup ID) |
| MC_ADDAXISTOGROUP | Ngõ vào (Input) | Axis         | WORD         | Không             | [0 to 65535]    | Số hiệu định danh trục (Axis ID)           |
| MC_ADDAXISTOGROUP | Ngõ ra (Output) | Done         | BOOL         | Có                | TRUE/FALSE      | Cờ báo hoàn thành (Done)                   |
| MC_ADDAXISTOGROUP | Ngõ ra (Output) | Busy         | BOOL         | Có                | TRUE/FALSE      | Cờ báo khối hàm đang bận thực thi (Busy)   |
| MC_ADDAXISTOGROUP | Ngõ ra (Output) | Error        | BOOL         | Có                | TRUE/FALSE      | Cờ báo có phát sinh lỗi hay không (Error)  |
| MC_ADDAXISTOGROUP | Ngõ ra (Output) | ErrorID      | DWORD        | Có                | -               | Mã lỗi (Vui lòng kiểm tra【8.10 Mã lỗi】)  |

#### Đặc tính kỹ thuật

▪Cạnh lên của Execute kích hoạt lệnh và Axis được thêm vào Axes Group. Các lệnh không được đệm (buffer) và trục không chuyển động;

▪IndentInGroup là cờ chỉ thị thứ tự thêm trục vào nhóm trục.

:::tip
✎Lưu ý:

▪Nếu số thứ tự của nhóm trục không tồn tại, hệ thống sẽ báo lỗi;

▪Khi nhóm trục đang được bật (Enable), nếu thêm trục mới sẽ báo lỗi;

▪Nhóm trục không thể chuyển động nếu mới chỉ thêm trục vào nhóm trục. Cần phải gọi MC_GroupEnable để cho phép chuyển động.
:::

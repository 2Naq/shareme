## Lệnh SDO

### MC_READSDO đọc dữ liệu SDO

MC_READSDO

Lệnh này dùng để đọc giá trị của từ điển đối tượng (Object Dictionary) Servo.

- [ MC_READSDO (S1) (S2) (S3) (D1) (S4) ]

#### Nội dung, phạm vi và kiểu dữ liệu

| Tham số | Nội dung mô tả | Phạm vi giá trị | Kiểu dữ liệu | Kiểu dữ liệu (Bảng) |
| :--- | :--- | :--- | :--- | :--- |
| (S1) | Chỉ số từ điển đối tượng SDO (Index) | - | Unsigned BIN16 | ANY16_U |
| (S2) | Chỉ số phụ từ điển đối tượng SDO (Subindex) | - | Unsigned BIN16 | ANY16_U |
| (S3) | Độ dài (đơn vị BYTE) | - | Unsigned BIN16 | ANY16_U |
| (D1) | Thiết bị đọc dữ liệu | - | Define the size according to S3. | - |
| (S4) | Chỉ định số trạm servo | - | Signed BIN16 | ANY16_S |

#### Đặc tính kỹ thuật

▪Đọc giá trị theo số trạm Servo (S4), chỉ số từ điển đối tượng (S1), chỉ số phụ từ điển đối tượng (S2) và độ dài (S3) vào thiết bị được chỉ định (D1).

:::tip
✎Lưu ý:

▪Khi có từ điển đối tượng tương ứng đã được cài đặt trong PDO, có thể xảy ra trường hợp SDO không thể đọc được.
:::

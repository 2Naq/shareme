### Lưu ý khi sử dụng vùng nhớ thiết bị

- - **LC** và **HSC** là kiểu dữ liệu 32-bit có dấu (Signed DWord/DINT);
- - **T, C, D, R và SD** là kiểu dữ liệu 16-bit có dấu (Signed Word/INT);
### Bảng thông số chân và kiểu biến (Variable Type Used)

| Khối lệnh | Kiểu chân | Tham số | Kiểu dữ liệu | Cho phép để trống | Phạm vi giá trị | Mô tả kỹ thuật |
| MC_CAMTABLESELECT | Ngõ vào (Input) | Execute | BOOL | Không | TRUE / FALSE | Enable |
| Periodic | BOOL | Không | TRUE / FALSE | Cyclic mode setting |
| MasterAbsolute | BOOL | Không | TRUE / FALSE | Master axis position mode setting |
| SlaveAbsolute | BOOL | Không | TRUE / FALSE | Slave axis position mode setting |
| Master | WORD | Không | - | Master axis |
| Slave | WORD | Không | - | Slave axis |
| CamTable | Cam table (INT type variable) | Không | - | Cam table |
| Ngõ ra (Output) | Done | BOOL | Không | TRUE / FALSE | Completion sign |
| Busy | BOOL | Không | TRUE / FALSE | Busy sign |
| Error | BOOL | Không | TRUE / FALSE | Cờ báo có phát sinh lỗi hay không |
| ErrorID | DWORD | Không | - | Error code |
| CamTableID | WORD | Không | - | Cam table identification number |
Chức năng và nguyên lý hoạt động

- When MasterAbsolute is true, it means the master axis is under the absolute mode; when MasterAbsolute is false, it means the master axis is under the relative mode;
- When SlaveAbsolute is true, it means the slave axis is under the absolute mode; when SlaveAbsolute is false, it means the slave axis is under the relative mode;
- This function block is used to bind the cam table, that is, to bind the input master axis, slave axis and cam table. When calling MC_CAMIN function block, only the cam table bound by this function block can be used.
Lưu ý kỹ thuật quan trọng

- Khối hàm này sẽ báo lỗi không khả dụng nếu số hiệu trục `Axis` không tồn tại trong cấu hình phần cứng.
Error code

| Error code | Content |
| 4084H | Data beyond the specifiable range was entered. |

✎Note:

1. This function block is not available when the Cam table does not exist.

2. The data written to ECAM table needs to be accurate to six decimal places, otherwise PLC will report error 16x00000C

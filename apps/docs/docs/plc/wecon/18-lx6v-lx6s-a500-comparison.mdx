## Cấu hình cơ bản

| Series | 6V | 6S | A500 |
| :--- | :--- | :--- | :--- |
| Chế độ chạy | Quét tuần hoàn / Ngắt |  |  |
| Lập trình | LD/FB/FC/ST |  |  |
| I/O | 0808 |  |  |
| Nguồn cấp | D: DC 24V |  |  |
| Loại ngõ ra | MT: Transistor |  |  |
| Thời gian thực thi | Basic 0.01 to 0.02μs |  |  |
| Dung lượng chương trình | 5M |  |  |
| Download & Monitoring |  |  |  |
| Download & Monitoring | Ethernet |  |  |
| Download & Monitoring | USB TYPE-C |  |  |
| Ngõ ra xung tốc độ cao | Loại Transistor 4 kênh / 200KHz | Loại Transistor 4 kênh / 200KHz | Loại Transistor 6 kênh / 200KHz |
| bộ đếm tốc độ cao (HSC) interrupt | 100 Channels |  |  |
| Ngắt bộ định thời (Timer) | 100 channels, supporting 0.1ms interrupt |  |  |
| Ngắt đầu vào ngoài | X0 to X7 (Rising & Falling) |  |  |
| Đầu vào tốc độ cao một pha | 4 channels 150kHz |  |  |

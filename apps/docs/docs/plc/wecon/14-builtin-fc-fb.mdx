## 14 Built-in FC/FB: Thư viện khối hàm mở rộng tích hợp

Thư viện khối hàm chuẩn hóa của phần mềm PLC Editor 2:
- Các khối hàm toán học mở rộng (LREAL, lượng giác SIN, COS, TAN, logarit).
- Các khối chuyển đổi cơ số (BIN, BCD, HEX, ASCII).
- Các khối hàm lọc tín hiệu số (Digital Filter) và bảo vệ quá dòng động cơ.

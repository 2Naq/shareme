## Appendixes: Phụ lục kỹ thuật & So sánh dòng PLC Wecon

Tài liệu tham khảo phần cứng chi tiết:
- Bảng so sánh dung lượng bộ nhớ chương trình, tốc độ xử lý CPU giữa các model LX6V, LX6S và LX6A500.
- Sơ đồ nguyên lý mạch đấu dây chân ngõ vào Sink/Source và ngõ ra Transistor NPN/PNP.
- Hướng dẫn bảo trì, pin lưu trữ thời gian thực (RTC) và quy trình sao lưu (Backup / Restore) chương trình.

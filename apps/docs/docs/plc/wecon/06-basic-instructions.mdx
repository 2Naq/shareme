## 06 Basic instructions: Tập lệnh logic cơ bản

Các lệnh nền tảng của ngôn ngữ hình thang (Ladder Diagram):
- Tiếp điểm thường mở (`LD`), thường đóng (`LDI`), nối tiếp (`AND`, `ANI`), song song (`OR`, `ORI`).
- Cuộn dây xuất ngõ ra (`OUT`), tự giữ (`SET`), xóa giữ (`RST`).
- Lệnh bắt cạnh sườn lên (`PLS`, `LDP`) và sườn xuống (`PLF`, `LDF`).

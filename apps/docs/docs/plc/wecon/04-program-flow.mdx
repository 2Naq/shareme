## 04 Program Flow: Điều khiển luồng chương trình

Bao gồm các lệnh điều hướng luồng thực thi:
- **CJ (Conditional Jump):** Nhảy có điều kiện qua một đoạn logic để tối ưu thời gian quét scan time.
- **CALL / SRET:** Gọi chương trình con (Subroutine) và quay trở về chương trình chính.
- **FOR / NEXT:** Vòng lặp cưỡng bức số lần lặp lại cho các thuật toán tính toán mảng dữ liệu.
- **EI / DI / IRET:** Cho phép hoặc vô hiệu hóa các chương trình xử lý ngắt phần cứng tốc độ cao.

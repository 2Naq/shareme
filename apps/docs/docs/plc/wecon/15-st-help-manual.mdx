## 15 ST Help Manual: Sổ tay ngôn ngữ Structured Text (ST)

Ngôn ngữ lập trình dạng văn bản cấu trúc bậc cao theo chuẩn IEC 61131-3:
- Cú pháp khai báo biến cục bộ (VAR), ngõ vào (VAR_INPUT), ngõ ra (VAR_OUTPUT).
- Cấu trúc điều kiện rẽ nhánh: `IF ... THEN ... ELSIF ... ELSE ... END_IF`.
- Cấu trúc lựa chọn trạng thái máy: `CASE ... OF ... END_CASE`.
- Các vòng lặp thuật toán: `FOR ... TO ... DO`, `WHILE ... DO`, `REPEAT ... UNTIL`.

## 11 PID Control Instruction: Thuật toán điều khiển vòng kín

Khối hàm PID chuyên dụng cho các hệ thống điều khiển liên tục:
- Cung cấp 3 thông số độc lập: Khâu tỉ lệ (P), khâu tích phân (I), khâu vi phân (D).
- Tích hợp giải thuật tự động nhận dạng và dò thông số tối ưu (Auto-tuning - AT).
- Bộ lọc thông thấp chống vọt lố và giảm nhiễu tín hiệu Analog cảm biến.

## 12 Character String Instruction: Xử lý chuỗi ký tự ASCII

Ứng dụng trong việc đọc dữ liệu từ máy quét mã vạch (Barcode / QR Code), máy in date và thẻ RFID:
- Ghép chuỗi, cắt chuỗi con (LEFT, RIGHT, MID).
- So sánh chuỗi ký tự và chuyển đổi giữa số nguyên/số thực sang chuỗi ký tự ASCII và ngược lại.
